What is Sentiment Analysis?

Sentiment Analysis is a Natural Language Processing (NLP) technique used to identify emotions and opinions expressed in text data.

About Our Project

Our project, Social Media Sentiment Analysis Using XGBoost, analyzes social media posts and comments to identify whether the sentiment is Positive, Negative or Neutral.

Our Objective

Our main objective is to make social media text analysis easier and faster using Machine Learning and the XGBoost algorithm.
